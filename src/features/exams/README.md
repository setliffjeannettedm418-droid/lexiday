`catalog.json` 只保存年份、篇号、来源网页和该篇公开 DOCX 下载链接。正文由用户首次手动打开时获取，保存在自己的设备与学习备份中。仓库和 APK 不含第三方完整真题正文、教师解析或参考答案库。

来源目录：https://english-exam.lazynote.cn/kaoyan/english-two/ 。年份网页与下载地址取自实际页面链接，来源站点为第三方整理的「懒笔记」，不是官方命题机构。每篇页面提供来源链接，参考答案/教师解析在来源页查看；App 内手动生成的句子解析明确标为 AI 内容。

2026-10-11 检查：68 个 DOCX 均可获取；生产 `parseExamText` 可识别全部正文与对应的五道题，题号范围分别为 21—25、26—30、31—35、36—40。这是结构与来源可用性检查，不代表对真题每字或教师答案作了独立校对。外部站点可能调整链接或内容，首次下载失败会保留旧缓存并显示重试提示。

Android 使用 CapacitorHttp 获取文件，DOCX 使用现有 Mammoth 解析，限制文件大小并校验题号。取消下载或离开页面后不接收迟到结果。本地 Vite 开发代理只允许固定资料来源路径；普通生产网页版直接访问来源，可能受跨域限制。主交付目标为 Android App。

加词使用现有离线词典与词形匹配：能确认原形时读取原形词条的音标和释义，复用词库已有 ID 及记录，今日清单与原句去重。没有模型解析时显示词典常见义；本句精确语境义须由用户手动请求解析。新增采集词不会产生答题记录或开启复习计时。
