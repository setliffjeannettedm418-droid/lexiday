# 词序 Lexiday

面向中国考研英语学习者的本地优先词汇测试 App。
核心循环：**导入 → 测试 → 判断掌握 → 错题与薄弱词巩固 → 间隔复习 → 80 词阅读巩固**。

## 第一版能力

- DOCX / XLSX / CSV / JSON 本地导入，预览可编辑、勾选、删除、归属日期、合并/覆盖/跳过重复词。
- 初始词库来自用户两份 Word：72 + 83 条，按词归并后 153 个。原始内容保留，学习记录初始为空。
- 英译中、中译英、熟词僻义、搭配、拼写、判断、智能混合。
- 答案解析后自评“不会 / 模糊 / 掌握”，不会自动跳题。
- 首轮所有选中词至少出现一次；默认自动继续巩固薄弱词，达到基本掌握后结束。可关闭自动巩固或保存本题后提前结束。
- 错题记录、mastery 0–4、复习时间、连续正误、最近 7 天统计。
- 浅色/深色/系统主题、响应式底部导航、键盘快捷键、设备语音。
- IndexedDB 持久化、刷新恢复会话、JSON 备份/恢复、清空二次确认。
- PWA manifest、应用图标、构建资源预缓存和导航离线回退。

## Android 独立安装包

Android 版使用 Capacitor 8 将应用代码、文件解析库、153 个初始单词、离线英汉词典和离线美式/英式语音一起封装到 APK。没有远程页面地址或登录系统；首次启动、导入、测试、发音、词典查词和阅读已保存文章均不需要网络或 VPN。生成新文章、手动补全、获取新的语境解析和拍照识词需要连接 DeepSeek 官方服务。

下载 APK 后，在手机的“文件管理 / 下载”中打开，按系统提示允许该文件来源安装应用。安装后从桌面的“词序”图标进入。无需添加网页快捷方式。支持 Android 7.0 及以上版本和可用的 Android System WebView。

导入通过系统文件选择器选择 DOCX、XLSX、CSV、JSON。备份和示例下载使用 Android 原生“保存到”窗口，选择本地文件夹即可；不申请全部文件访问权限。卸载或清除应用数据会删除学习记录，请先导出备份。网站和 APK 的数据互相独立，已有网页记录可先导出 JSON，再在 App 的设置页恢复。

### 自行构建 APK

安装 Node.js 22.13+、完整 **JDK 21**、Android SDK Platform 36、Build Tools 35.0.0 / 36.0.0，在 `android/local.properties` 中配置本机 `sdk.dir`。然后运行：

```sh
npm ci
npm run android:apk
```

产物为 `android/app/build/outputs/apk/debug/app-debug.apk`，由本机调试证书签名，可直接安装测试，未上架应用商店。后续覆盖安装必须使用相同签名；换签名前先导出数据。正式发行可在 Android Studio 中配置个人 release 签名。首次构建需要网络获取工具，安装后的基本学习功能不需要网络。

工程保留官方 Google/Maven Central 源，可在 Gradle 命令追加 `-PlexidayMirror=true` 切换镜像。不要把临时代理地址或签名私钥提交到 Git。

## 数据存储

Dexie 数据库 `lexiday-v1` 持久保存词库、每日词表、学习记录、答题日志、设置与阅读批次。当前进行中的会话存于 localStorage，刷新可继续。答题选项与自评后点击“下一题/保存并继续/完成测试”提交该题，提交使用唯一 attempt ID 去重。

答题记录保存在本机。文章生成发送当篇 20 个目标词及其词义、搭配；手动补全待核对词时，还发送该篇已有英文正文。阅读查词的词典查询在本地完成；手动获取本句详解仅发送所选词及位置、所在句和该句译文。不发送 Word 原文件、文件名、答题记录或整本词库。拍照识词仅发送本次手动选择且确认识别的照片，照片不写入学习备份。不同浏览器、设备和域名相互独立。设置 → 导出全部数据可备份，包含已保存文章、详解和阅读查词的语境缓存，不含 API 密钥；导入备份经过格式校验与二次确认，并关闭自动生成。

## 调度策略

答错或自评不会：mastery 1，5 分钟后到期；模糊：mastery 2，6 小时后到期；连续答对且自评掌握：mastery 2 → 3 → 4，间隔 1 → 3 → 7 天。初始 mastery 为 0。排序优先错误、到期、模糊词与熟词僻义。首轮结束后自动强化按同样优先级进行，每次补充最多 10 题；可随时保存本题后结束。

## 键盘

非输入框焦点：1–4 选择选项，Space 显示答案并计为未答对，N 不会、M 模糊、K 掌握，Enter 提交本题并继续。拼写框中 Enter 仅提交拼写，不拦截正常文本输入。

## Android 1.3：每 80 词阅读巩固

设置 → 80 词阅读巩固 → 在手机上填写自己的 DeepSeek API 密钥，选择 Flash 或 Pro，了解发送范围与按量费用后保存并启用。App 不提供共享密钥或代充值；具体费用以 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/pricing/) 为准。Android 使用系统密钥库 AES-GCM 加密存储密钥；网页版仅保存在当前页面内存，可能受服务端跨域限制。

“已学”按已提交测试的不同单词计数，跨天累计，答错也计入；仅导入、打开词条或重复复习不增加新词数。每 80 词保存一个词汇快照，拆成 4 篇各覆盖 20 词的原创短文，避免把 80 词硬塞入一篇。额外的第 81 词进入下一组进度。正文覆盖和详解完整性经程序核对；AI 语法、译文与语义准确性仍需学习者按需核对教材。

打开 App、联网且配置有效时，开启自动生成后按顺序处理新批次。每篇独立保存，译文及语法默认收起，点击高亮单词可看语境义、搭配、易错点和另一个应用例句。已完成文章和详解可离线阅读。

历史词汇升级时自动归集，但需手动启动生成。网络错误、余额不足或应用关闭时保留已完成文章，不自动重试付费请求；“继续生成剩余短文”只补尚未完成的篇数。暂停或中断的请求可能已计费。生成请求每篇上限 12,000 输出 token，一组通常发起 4 次请求；没有配置密钥时只统计进度，不调用服务。

## Android 1.4：通用词汇匹配修复

正文定位、高亮和覆盖统计使用统一匹配规则，对之后导入的词也生效。支持常见规则变形、WordNet 不规则名词/动词/形容词、连续短语的词形变化，以及大小写、全半角、弯引号与连字符差异。匹配保留原文位置，并按词边界核对，不把包含目标字符串的派生词自动当作已覆盖。模型给出的句子编号有误或缺失时，从实际正文重新定位。

结构完整的文章即使有词无法定位也会保存，显示实际覆盖数和待核对词。确实漏词、特殊拼写或尚未识别的表达不会被虚报为已覆盖，也不会再仅因词汇定位失败而丢弃整篇文章。可继续阅读，或手动点击“补全本篇待核对词”；只重新生成所选一篇，不自动追加付费请求。请求失败或新结果的待核对词更多时，保留原文。译文、语法和词义应用仍按需手动查看。

升级或导入备份时会在本地重新核对已保存文章，不触发 API 调用。旧版因报错未保存的文章没有可恢复正文，需要手动继续生成。

## Android 1.5：正文生词随点随查
